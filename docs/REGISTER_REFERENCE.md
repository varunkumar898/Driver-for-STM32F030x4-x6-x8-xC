# Register Reference

The register layout and peripheral availability are based on STMicroelectronics
RM0360 for STM32F030x4/x6/x8/xC and the STM32F030R8 datasheet.

Reference:
- RM0360: https://www.st.com/resource/en/reference_manual/rm0360-stm32f0x1-advanced-armbased-32bit-mcus-stmicroelectronics.pdf
- STM32F030R8 datasheet: https://www.st.com/resource/en/datasheet/stm32f030r8.pdf

The startup vector ordering follows ST's STM32F030x8 GCC startup template.
